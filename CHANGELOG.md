# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/) and this project adheres to [Semantic Versioning](http://semver.org/).

## [1.1.0] - 2026-09-23
- Added configuration option `badgeText` to configure the text shown inside the badge.
- Added configuration option `hideBadge` to hide the badge and only gray out the image on out-of-stock products.
- Show the badge in product sliders and the favorites list, in addition to the PDP and product lists.

## [1.0.0] - 2020-01-29
- Initial extension release.
